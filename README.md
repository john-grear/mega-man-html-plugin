# Mega Man Animation Plugin

##### Welcome to the Mega Man Animation Plugin!

This little gem is designed to bring iconic Mega Man animations and movements to life. Whether you’re nostalgic for 8-bit adventures or simply want to add some pixel-perfect action to your site, this plugin is here to give your web page a bit of Mega flair.

## Features

- Controls
  - WASD / Arrow Keys for movement
  - Space / Z for jump
    - Down + Jump for slide
  - Shift / X / Left Click for attack
- Animations
  - Spawn
  - Death
  - Idle
  - Walk
  - Jump
  - Slide
  - Attack
  - Charge
- Sound Effects
  - None so far
